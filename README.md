# 🌸 Glow Agreements

Glow Agreements is a modern and unique web application that allows **payers** and **payees** to create, manage, and track agreements in a visually appealing, girly-themed interface.  
It’s built with **React + TailwindCSS**, featuring **role-based authentication**, **toast notifications**, and a playful **gradient UI**.  

---

## ✨ Features
- 🔐 Role-based login (Payer / Payee)  
- 📜 Create and view agreements  
- 🎨 Girly modern UI with gradients and soft floating decorations  
- 📱 Fully responsive design  
- 🔔 Hot-toast feedback (success/error messages)  
- 🖼 Lucide icons for a clean consistent icon set  

---

## 🛠 Tech Stack
- **Frontend:** React, React Router  
- **Styling:** TailwindCSS, Framer Motion  
- **UI Enhancements:** Lucide Icons, React Hot Toast  
- **Backend:** Nodejs, Express
